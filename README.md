# AvaLens

Аналитическая система комплексного анализа криптовалюты Avalanche (AVAX): технический,
фундаментальный, ончейн-анализ и анализ настроений с интегральной оценкой и показателем
достоверности. Актив сравнения — Ethereum (ETH).

Практическая работа № 3–2 по дисциплине «Блокчейн-технологии в экономике».

## Запуск

Нужен Python 3.11 или новее.

```
pip install -r requirements.txt
streamlit run app.py
```

Откроется страница `http://localhost:8501`. При первом запуске нажмите **«Обновить данные»**
в боковой панели: система опросит источники (до минуты) и выполнит расчёт.
Кнопка **«Рассчитать и сохранить»** записывает расчёт в историю.

Ключи API не нужны. Данные и история хранятся в файле `avalens.db` рядом с программой.

### Тестовый режим без интернета

```
set AVALENS_TEST_MODE=1        (Windows, cmd)
$env:AVALENS_TEST_MODE="1"     (Windows, PowerShell)
export AVALENS_TEST_MODE=1     (Linux, macOS)
streamlit run app.py
```

Источники заменяются имитацией (`tests/fake_api.py`), данные синтетические, база отдельная
(`avalens_test.db`), в интерфейсе показано предупреждение. Режим нужен для проверки работы
программы; для анализа реального рынка он не годится.

### Тесты

```
python -m pytest tests -v
```

25 тестов: ручная проверка SMA, EMA, RSI, полос Боллинджера и формулы интегральной оценки
(`tests/test_math.py`) и восемь тестовых ситуаций из задания (`tests/test_scenarios.py`).
Сеть тестам не нужна.

## Разделы интерфейса

| Раздел | Что показывает |
| --- | --- |
| Главная панель | цена, изменение, время обновления, интегральная оценка S, Confidence Score, состояние источников |
| Технический анализ | свечной график с SMA, EMA, полосами Боллинджера и уровнями; объём, RSI, MACD; тренд и сигналы |
| Фундаментальный анализ | капитализация, FDV, токеномика; баллы по 8 направлениям с экономическим следствием; сравнение с ETH |
| Ончейн-анализ | активные адреса, транзакции, комиссии, TVL, стейкинг; динамика и сопоставление с ценой |
| Анализ настроений | число публикаций, доли по тональности, динамика, значимые события; ручная проверка классификации |
| Комплексный анализ | оценки модулей, S, противоречия, риски, заключение, выгрузка отчёта |
| История и данные | сохранённые расчёты, проверка воспроизводимости, журнал источников, исходные ответы |

В каждом аналитическом разделе есть вкладки «Как посчитано» и «Исходные данные».
Тема (светлая или тёмная) и цветовая схема Material 3 переключаются внизу боковой панели.

## Структура проекта

```
app.py                  интерфейс Streamlit
core/pipeline.py        оркестратор: refresh() — загрузка, analyze() — расчёт
data/sources/           7 адаптеров источников с общим сценарием запроса (base.py)
data/quality.py         пропуски, аномалии, устаревание, расхождение источников
analysis/technical.py   индикаторы и оценка TA
analysis/fundamental.py 8 направлений и оценка FA
analysis/onchain.py     динамика показателей сети и оценка ON
analysis/sentiment.py   словарная тональность и оценка SA
analysis/integral.py    интегральная оценка S, Confidence Score, противоречия
storage/db.py           SQLite, 9 таблиц
report/report.py        аналитическое заключение (Markdown)
ui/                     тема Material 3, компоненты, графики
config/assets.yaml      реестр активов, ленты новостей, надёжность источников, пороги актуальности
fundamentals/*.yaml     справочные факты о проектах с источниками и датой проверки
tests/                  тесты и имитация API
```

## Источники данных

| Источник | Что берётся |
| --- | --- |
| Binance Spot API | дневные свечи, текущая цена |
| CoinGecko (без ключа) | капитализация, FDV, предложение; резервный ценовой ряд |
| Avalanche Metrics API | активные адреса, транзакции, комиссии C-Chain; число валидаторов и делегаторов |
| DefiLlama | TVL, комиссии в долларах, объём DEX, число протоколов |
| RSS криптоСМИ и Google News | новости |
| Reddit | посты сообщества |
| Alternative.me | индекс Fear & Greed |

Индекс Fear & Greed сохраняется в таблице `onchain_metrics` под условным активом `MARKET`.

## Как добавить криптовалюту

1. Добавить запись в `config/assets.yaml` (тикеры в источниках, ключевые слова, набор ончейн-показателей).
2. Создать `fundamentals/<тикер>.yaml` по образцу `avax.yaml`.

Код модулей менять не нужно.

## Ограничения

- Система не даёт инвестиционных рекомендаций и не прогнозирует цену.
- Шаг анализа — сутки; значения за текущие незавершённые сутки не используются.
- Рыночные снимки (капитализация, FDV) и публикации накапливаются с момента первого запуска,
  поэтому для периодов раньше него фундаментальный анализ и настроения могут быть недоступны.
- Тональность определяется словарём для английского языка; сарказм распознаётся по маркерам.
- На 16.11.2026 показатели стейкинга в Avalanche Metrics API заканчивались 31.08.2026:
  устаревший показатель система исключает из оценки и снижает достоверность.
- Справочные факты в `fundamentals/*.yaml` нужно перепроверять по источникам, указанным в файле.
